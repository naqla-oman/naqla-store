# WhatsApp templates (English) to submit to Meta — __SHORT_EN__

Created from **WhatsApp Manager → Message templates → Create template**, language **English (en)**.
After approval, put each template's name in `apps/backend/.env` (variable under each template). Orders placed from the English storefront (`order.locale = en-US`) use these templates; until a template is approved, the Arabic one is sent instead.

Meta rules respected below:
- The body does not start or end with a variable.
- Variables are numbered sequentially in order of appearance ({{1}}, {{2}}…).
- A **sample value per variable** is required on submission (the "Sample" column).
- Order templates are **Utility**; the login-code template is **Authentication**.

The texts match exactly what the server writes to the log in development (`src/lib/order-notifications.ts`, `build(kind, vars, "en")`). When no first name is available the greeting variable is `there` ("Hello there, …").

Hello {{1}}, we received your order {{2}} for {{3}}. We are preparing it now, and you can track it here: {{4}} — thank you for shopping at __SHORT_EN__.

## Login code
The Authentication template (`WHATSAPP_OTP_TEMPLATE`) is generated by Meta in the template's language; one Arabic template is used for both storefront languages for now (the code itself is numeric). An English Authentication template can be added later as `WHATSAPP_OTP_TEMPLATE_EN` once the login request carries the page language.

## Merchant alert
`merchant_new_order` is for the merchant's own phone and stays Arabic — no English version.

## After approval — `apps/backend/.env`
```
WHATSAPP_TPL_ORDER_PLACED_EN=__SLUG___order_placed_en
WHATSAPP_TPL_ORDER_SHIPPED_EN=__SLUG___order_shipped_en
WHATSAPP_TPL_ORDER_READY_PICKUP_EN=__SLUG___order_ready_pickup_en
WHATSAPP_TPL_ORDER_DELIVERED_EN=__SLUG___order_delivered_en
WHATSAPP_TPL_ORDER_SHIPPED_COURIER_EN=__SLUG___order_shipped_courier_en
WHATSAPP_TPL_ORDER_CANCELED_EN=__SLUG___order_canceled_en
WHATSAPP_TEMPLATE_LANG_EN=en
```
Any English template left empty is not sent and does not block the order: the Arabic template is used instead (logged as info).
